# Razorpay Clone 💳
A frontend clone of the Razorpay website built using HTML, Tailwind CSS, and Vite.

## 🚀 About the Project
This project is a recreation of the Razorpay landing page, built as part of my frontend development learning journey.

The goal was to practice modern web design, understand Tailwind CSS utilities, and build a structured landing page inspired by a real-world product website.

## ✨ Sections Implemented

- Navigation Bar
- Hero Section
- Payment Suite
- Business Banking
- New Product Suite
- Core Features
- Testimonials
- Call-to-Action Section
- Footer with Newsletter Form

## 🛠️ Tech Stack

- **HTML5** – Page structure
- **Tailwind CSS v4** – Styling and layouts
- **Vite** – Development server and build tooling
- **Google Fonts (Mulish)** – Typography
- **Font Awesome & Feather Icons** – Icons

## 💻 Run Locally
Make sure Node.js and npm are installed.

1. Clone this repository:

```bash
git clone https://github.com/Moinul-hasan-786/razorpay-clone.git
```

2. Navigate to the project folder:

```bash
cd razorpay-clone
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the localhost URL displayed in your terminal.
